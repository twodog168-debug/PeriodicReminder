周期提醒 Android 项目（无需在自己的电脑安装 Android Studio）

这个压缩包是“项目源码 + GitHub 云端自动编译配置”，不是已经编译好的 APK。
我无法在当前对话中直接访问你的 GitHub 账号，因此需要你把 ZIP 上传到自己的 GitHub 仓库一次。

最简操作：
1. 登录 https://github.com 并创建一个空仓库，名字例如 PeriodicReminder。
2. 解压本 ZIP。
3. 将解压后的所有文件和文件夹上传到仓库根目录（必须包含 .github 文件夹）。
4. 上传完成后，打开仓库的 Actions 页面。
5. 如果看到工作流，进入 “Build Android APK”，点击 Run workflow；如果没有，先刷新页面。
6. 等待任务完成，点开本次运行记录，在 Artifacts 区域下载 PeriodicReminder-debug。
7. 解压下载的 artifact，得到 app-debug.apk，传到手机安装。

以后修改代码并推送到 main 分支，也会自动编译。

重要说明：
- 首次安装是 debug 测试签名 APK。不要卸载后再安装不同签名的版本，否则可能需要先备份数据再卸载。
- Android 13+ 需要允许通知权限。
- Android 12+ 需要允许精确闹钟；如果没有授予，系统可能延迟提醒。
- 小米 MIUI 还可能需要在系统设置中允许通知、自启动，并关闭该应用的电池限制。
- 不需要常驻前台服务；系统闹钟到点唤醒广播接收器发通知。
- 若用户在系统设置中“强行停止”应用，安卓会停止其闹钟，直到用户再次手动打开应用。
- 手机关机期间无法发通知；开机后会恢复任务。关机期间错过的提醒不会逐条补发，而是开机后补一次并重新计时。
- 当前版本为基础可运行原型，建议先用 1 分钟间隔、循环 2 次测试通知、锁屏和重启行为，再用于重要提醒。
